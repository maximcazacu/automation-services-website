# Redesign brief

Create a distinct Romanian B2B website and identity for Maxim Cazacu's automation services. The current name, logo, favicon and social card are rejected and must be replaced. Do not make cosmetic variations of the current mark or adopt another existing business's identity.

## Preserve the functional requirements

- Lead with Microsoft Copilot Studio agents; support the offer with Microsoft 365 workflow automation and Excel/reporting services.
- Keep the contact flow as a request for a discussion or quotation, with no checkout or payment obligation.
- Keep demos clearly fictitious. Do not invent clients, results, testimonials, affiliations, licenses or approvals.
- Preserve the retail operations pilot selection and existing service codes: `copilot`, `workflows`, `excel`, `other`. The pilot currently called Ops maps to `workflows`.
- Keep the email draft, functional mailto, copy fallback and clear instruction that visitors send the email from their own application.
- Keep accessibility: keyboard navigation, visible focus, associated labels/errors, status announcements, mobile reflow and legible text.
- Keep analytics, external bookings, persistent demo preferences and the public API disabled.
- Maintain provider/privacy/storage routes and a consistent footer. Do not invent missing company or GDPR facts.
- Keep all private/operational files outside the deployment allowlist.

## Replace and review

1. Develop a new name only after checking existing businesses, domain use and relevant brand conflicts. Search results alone do not establish availability.
2. Create an independent logo concept, favicon, social preview and visual system with documented provenance.
3. Rethink page composition, navigation, typography and wording around the actual offer. The current structure is a reference for functionality, not a required design template.
4. Review the resulting brand and design with the owner before treating them as approved.
5. Update every visible reference, metadata field and asset; preserve existing routes or provide explicit compatibility redirects when renaming them.

Use the neutral repository name as a working label. It is not a proposed public brand.
